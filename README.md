# Tamehouse

Tienda online para la venta de merchandising (poleras, vinilos, etc.), con pago, envío y notificaciones automatizadas.

## Stack

- Next.js + Tailwind CSS
- Supabase (base de datos, autenticación, storage)
- Getnet (pago)
- API Chilexpress (envío)

## Trabajo con Git

- `main` → versión estable
- `dev` → donde se junta el trabajo de ambos
- `feature/nombre` → una rama por tarea, creada desde `dev`

Nunca se trabaja directo en `main` ni `dev`.
